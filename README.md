# จอมบึง มาราธอน (Chombueng Marathon)

โปรเจกต์เว็บแอปพลิเคชันจัดการงานวิ่งจอมบึง มาราธอน ซึ่งระบบถูกออกแบบเป็น Full-Stack ควบรวมระหว่าง:
1. **Frontend (หน้าเว็บ):** พัฒนาด้วย PHP และ CSS บริสุทธิ์ (Vanilla CSS) เน้นความสวยงามและเปิดง่าย
2. **Backend (ระบบหลังบ้าน):** พัฒนาด้วย Node.js (Express) สำหรับทำ API รับส่งข้อมูลผู้สมัคร

---

## 📂 โครงสร้างโปรเจกต์ (Project Structure)

```text
marathon/
├── index.php           # โครงสร้างหน้าเว็บหลัก (Frontend)
├── style.css           # สไตล์ของหน้าเว็บให้ดูพรีเมียม
├── package.json        # ตั้งค่า Dependencies ของระบบ Backend
├── .env                # ไฟล์สำหรับตั้งค่า Environment ตัวแปรระบบ เช่น รหัสผ่านฐานข้อมูล
└── src/                # โค้ดทั้งหมดของ API หลังบ้าน (Node.js)
    ├── index.js        # ไฟล์รันเซิร์ฟเวอร์หลัก (Entry Point)
    ├── routes/         # กำหนดเส้นทาง URL ทั้งหมด (Endpoints)
    ├── controllers/    # ประมวลผลและจัดการ Request จากผู้ใช้
    ├── services/       # ตัวกลางจัดการ Logic ต่างๆ (เช่น เซฟข้อมูลลง Database)
    ├── config/         # การเชื่อมต่อฐานข้อมูล (Database Config)
    └── middleware/     # ตรวจสอบความถูกต้องและสิทธิ์ผู้ใช้ (Authentication)
```

## 🚀 วิธีการติดตั้ง (Installation Setup)

ก่อนเริ่มใช้งานเครื่องของคุณจำเป็นต้องมี **Node.js** และ **PHP** ติดตั้งอยู่

1. **โคลนหรือเปิดโฟลเดอร์โปรเจกต์:**
   เข้าไปที่โฟลเดอร์ `marathon/` ด้วยโปรแกรม Terminal / Command Prompt
   ```bash
   cd marathon
   ```

2. **ติดตั้งแพ็กเกจของระบบหลังบ้าน:**
   ```bash
   npm install
   ```

3. **ตั้งค่าฐานข้อมูลและระบบ (.env):**
   ตรวจสอบให้แน่ใจว่าได้ระบุค่าพอร์ตการทำงานและฐานข้อมูลไว้ในโปรเจกต์เรียบร้อย (ไฟล์ `.env`)
   ```env
   PORT=5000
   DB_HOST=localhost
   DB_USER=root
   DB_PASSWORD=
   DB_NAME=chombueng_marathon
   ```

## 💻 วิธีการรันโปรเจกต์ (How to Start)

เนื่องจากระบบหน้าเว็บและหลังบ้านแยกจากกันอย่างเป็นสัดส่วน คุณจำเป็นต้องเปิด Terminal **2 หน้าต่าง** ในการรัน:

### 1. วิธีสตาร์ทระบบหลังบ้าน (Backend API)
เปิด Terminal สู่หน้าต่างที่ 1 แล้วพิมพ์:
```bash
npm run dev
```
🎉 ระบบหลังบ้านจะพร้อมให้บริการที่: **http://localhost:5000** 
*(ทดสอบ API ข้อมูลงานวิ่งได้ที่ `http://localhost:5000/api/info`)*

### 2. วิธีสตาร์ทหน้าเว็บ (Frontend PHP)
เปิด Terminal สู่หน้าต่างที่ 2 (ต้องอยู่ในโฟลเดอร์ `marathon/` ด้วยเช่นกัน) แล้วพิมพ์:
```bash
php -S localhost:8000
```
🎉 หลังจากนั้นเปิดเบราว์เซอร์ไปที่: **http://localhost:8000**
*(คุณจะพบกับหน้าเว็บจอมบึงมาราธอนดีไซน์สวยงามที่เราสร้างไว้!)*

## 📝 หมายเหตุ (Notes)
- การใช้ `npm run dev` จะอาศัย `nodemon` ในการรัน ซึ่งมันจะรีเฟรช API ให้คุณอัตโนมัติหากมีการแก้ไขไฟล์ในโฟลเดอร์ `src/`
- โปรเจกต์นี้สามารถนำไปต่อยอดใช้คู่กับโปรแกรม XAMPP หรือ Laragon ได้ (โดยย้ายโปรเจกต์ไปไว้ใน `htdocs` หรือ `www`) แล้วเข้าผ่าน `http://localhost/marathon` ได้เลย โดยตัว Node.js ก็นำไปพอร์ตต่างหาก
